A collection of smaller IoT projects built alongside the larger ones on this
page — quicker builds exploring sensors, connectivity, and small home
automations.

## Examples

- Sensor nodes reporting environmental data (temperature/humidity) over
  Wi-Fi to a small local dashboard
- Small automation triggers (e.g. relay control based on sensor thresholds)
- Prototyping with common IoT dev boards and low-power radio modules

These projects were mostly about fast iteration — trying an idea, wiring it
up, and seeing if it worked, rather than long-term builds.
